## 🎨 Technologies utilisées

- **HTML5** – Structure du contenu  
- **CSS3** – Mise en page, flexbox, responsive design  
- **Media Queries** – Adaptation mobile/tablette  
- **Flexbox** – Pour organiser les sections, les blocs et les testimonials  

---

## 🧱 Démarche & Logique du CSS

### ✔️ 1. Reset global  
Utilisation du sélecteur `*` pour annuler margin/padding et définir `box-sizing: border-box`.

### ✔️ 2. Structure générale  
- `.card-container` pour centrer et limiter la largeur du contenu  
- `.header` pour organiser le titre + les niveaux  
- `.niveaux` et `.niveau` pour les cartes de ratings  
- `.temoignages`, `.temoin` et `.temoin1` pour les témoignages  

### ✔️ 3. Utilisation poussée de **Flexbox**  
- Alignements horizontaux et verticaux  
- Organisation en colonnes ou en lignes selon la taille de l’écran  

### ✔️ 4. Composants stylisés  
- Cartes arrondies (border-radius: 10px / 15px)  
- Hover states pour rendre l’interface plus dynamique  
- Couleurs inspirées d’un thème violet (#3d0a4e / #4b0a63)  

### ✔️ 5. Responsive design  
Deux points de rupture importants ont été utilisés :  
- `@media (max-width: 768px)` → tablette/mobile  
- `@media (max-width: 320px)` → petits smartphones  

Les sections passent en **colonne**, les marges sont ajustées et les étoiles sont recentrées.
